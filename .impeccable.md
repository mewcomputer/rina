## Design Context

### Users

Rina is a personal iPhone workspace for a technically sophisticated person who moves between conversations, providers, models, artefacts, sources, and contexts. Settings are visited during focused setup and debugging, not as a destination for browsing.

### Brand Personality

Calm, direct, quietly expressive, native to iOS, late-night, capable, and trustworthy.

### Aesthetic Direction

Dark-first with light-mode support from `theme_manifest.json`. Use system settings conventions, left alignment, restrained surfaces, and selective Liquid Glass only for floating or interactive controls. Avoid glass on lists and sidebar rows. Use progressive disclosure for advanced provider, web, privacy, and diagnostic controls.

### Design Principles

- show the common path first
- organize around user goals, not implementation details
- keep provider and model infrastructure replaceable and secondary to user work
- preserve native iOS behavior, Dynamic Type, and accessibility
- make risky network and credential options explicit
