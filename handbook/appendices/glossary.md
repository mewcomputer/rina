# Appendix A — Glossary
**Application service:** coordinator translating intent into operations.
**Artefact:** durable editable work with stable identity.
**Canonical block:** provider-independent response content.
**Canonical stream event:** provider-independent generation event.
**Content address:** identifier derived from content bytes.
**Context:** reusable assembly of existing objects.
**Provider adapter:** boundary translating a provider API.
**Relationship:** typed graph edge without containment.
**Revision:** immutable historical artefact state.
**Stable interface:** contract intended to change infrequently.
**Replaceable component:** implementation expected to evolve.
