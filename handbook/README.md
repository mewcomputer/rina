# The Handbook
**Draft 0.1 — Pre-Implementation Edition**

A native, local-first iOS workspace for intelligent systems.

## Structure
1. Philosophy — why the application exists.
2. Product — the concepts it exposes.
3. Specifications — the behaviour it promises.
4. Architecture — the implementation that fulfils those promises.

The user's work is the centre of the product. Providers and models are replaceable infrastructure.
